# CRM Autopilot

A FastAPI service that simulates a CRM and will later integrate with LLMs and LangGraph.

## Overview
- PostgreSQL database (same name as repo)
- FastAPI endpoints for task submission and status
- Initial version includes a simulated CRM data model.

## Development
Run locally with Docker Compose:
```bash
docker compose up --build
```

## Deploy
Will be deployed on Render from the same GitHub repo.
